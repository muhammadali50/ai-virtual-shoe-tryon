# Project workflow

Read `compreport.txt` before starting any task in this project. After each completed task or meaningful milestone, update the affected feature statuses, verification results, and backlog items, then append a dated work-log entry before reporting completion. Record what changed, why, which files changed, what you verified, and what remains. Keep previous work-log entries. If you are blocked or stop mid-task, record the current state and the next concrete action so another session can resume.
